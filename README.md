# 江湖閒談錄｜放置打怪

金庸／古龍**風格**的原創江湖放置網頁：創角、掛機打怪、掉寶、裝備、升級。

- 繁體中文介面
- 進度存於瀏覽器 localStorage（`jianghu-idle-v1`）
- 純靜態，可開 GitHub Pages
- 地圖 **10 區**（邊城→天脊），等級約 Lv1～42+
- 戰鬥舞台：主角左／敵人右，門派色＋兵器圖示／區域怪外觀，攻擊晃動與傷害數字
- **名號對手**：十區具名對手（日限 1、同區冷卻 4h、3～5% 遭遇），破後地圖顯示「已破」
- **俠義可花**：稱號／解鎖傳聞／軟化三選一
- **茶樓一敘**：掛機隨機二選一事件（可跳過）

> 本作為原創小品，僅致敬武俠氛圍，**不使用**金庸／古龍小說原文或官方設定稿。

## 本地

用瀏覽器直接開 `index.html`，或：

```bash
python3 -m http.server 8080
```
