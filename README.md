# 江湖閒談錄｜放置打怪

金庸／古龍**風格**的原創江湖放置網頁：創角、掛機打怪、掉寶、裝備、升級。

- 繁體中文介面
- 進度存於瀏覽器 localStorage（`jianghu-idle-v1`）
- 純靜態，可開 GitHub Pages
- 地圖 **10 區**（邊城→天脊），等級約 Lv1～42+

> 本作為原創小品，僅致敬武俠氛圍，**不使用**金庸／古龍小說原文或官方設定稿。
